# SubscriptIQ deployment source

The interactive app is published at **https://tizkglame.github.io/SubscriptIQ/**.

This directory contains the generated static demo for the repository's existing GitHub Pages configuration (`main:/docs`). `.nojekyll` serves the built app directly. `index.html` and `assets/` are generated by `npm run pages:prepare`; commit them with their source changes. CI checks that they stay in sync.

The demo uses a browser-local PostgreSQL runtime and sample data. It opens as admin, supports the catalog, billing, team and customer portal workflows, and persists changes in each visitor's browser. Hash routes support navigation and refreshes without a server. The demo is a preview; browser-only sign-in is not a security boundary for shared data.

See the [README](https://github.com/tizkglame/SubscriptIQ#readme) for the full local Node/PostgreSQL application, Docker startup, backups and verification.
